# v3.1 Release Notes

## Scope

v3.1 is the second isolated research release of mesh-aligned piecewise-linear
NVP surface parameterization. It keeps the v3.0 structural guarantee—no
rollback, no flip barrier, and no intersection penalty—while improving global
and boundary expressiveness and numerical training control. The retained v2.4
Affine/Spline pipeline is unchanged and remains available as a baseline.

Generated checkpoints, plots, experiment outputs, caches, and operational
server notes are not versioned. Only code, tests, documentation, configuration,
and `data/input/` meshes are included in Git.

## Main changes from v3.0

- Three-stage certified composition: `H1 -> local spline PL-NVP -> H2`.
- Exact legal scalar intervals for conditional rational-quadratic spline
  coupling; every finite spline output remains inside the current one-ring
  feasible region.
- Global radial Fourier and multiscale C0 boundary-hat modes, each constrained
  to its exact connected positive-area coefficient interval.
- Automatic removal of boundary-hat scales that are undersampled by a mesh.
- Six-ring scaffold with geometry-aware displacement decay to a fixed convex
  outer boundary.
- `atanh` radial conditioning model and normalized conditioning-risk metrics.
- Initial risk-based LR scaling, 100-step warm-up, dynamic high-risk LR caps,
  and conservative LR recovery after sustained risk headroom.
- A reproducible YAML release preset read by the v3.1 runner.
- Local spline iterations increased from 200 to 500 after five-mesh ablation.

## Default command

```powershell
python -m research.mesh_pl_nvp.run_harmonic_local `
  --config research/mesh_pl_nvp/v3_1_default.yaml `
  --input data/input/Balls/Balls.obj `
  --output-dir data/output/mesh_pl_nvp/v3.1/Balls
```

Explicit command-line options override YAML values. See
`research/mesh_pl_nvp/RUN_PIPELINE_CN.md` for every input command and parameter.

## Release defaults

- Tutte circle initialization with geometry scaling.
- H1 100 iterations, local spline 500 iterations, H2 100 iterations.
- Two harmonic cycles and four local color cycles; hidden dimension 32.
- Frequencies 2–5 and boundary hats 4/8/16/32 with support auto-selection.
- Eight rational-quadratic spline bins and tail bound 8.
- Six scaffold rings, scale 1.1, transition exponent 3, geometric mode profile.
- Adam LR 0.02 for harmonic stages and 0.003 configured for the local stage.
- Initial local-risk threshold 0.85, dynamic reduction threshold 0.95.
- LR recovery below risk 0.94 after 20 safe steps, every 10 steps by 1.05,
  capped at the mesh-specific safe peak.
- CUDA and float64; `--device cpu` remains supported.
- Original-face, 3D-area-weighted symmetric Dirichlet is the only objective.

## Five-mesh validation

The release configuration was run with seed `20260906` on every non-00027
input. All original meshes and extended scaffolds finished with zero flipped
faces, zero proper self-intersections, positive minimum area, and rollback
disabled.

| Mesh | area-weighted SD | p95 SD | p99 SD | LR recoveries |
|---|---:|---:|---:|---:|
| Balls | 4.683971 | 8.4544 | 24.8782 | 0 |
| Cow | 15.062505 | 73.1454 | 195.2627 | 11 |
| David328 | 13.061680 | 52.5409 | 130.4430 | 0 |
| Isis | 8.361489 | 20.4522 | 36.6147 | 0 |
| NefertitiFace | 4.806923 | 6.4779 | 8.0308 | 0 |

Increasing the local stage from 200 to 500 iterations reduced area-weighted
SD on all five meshes. LR recovery triggered only on Cow; on the other meshes
it made no parameter update and therefore introduced no observed side effect.
The release continues to optimize only mean area-weighted SD, so extreme-face
statistics are diagnostics rather than objectives.

## Guarantees and limitations

For a valid disk input, a simple fixed scaffold outer boundary, and successful
finite-precision execution, each layer preserves positive extended-face
orientation. The resulting extended PL disk map is globally injective, and the
original submesh is flip-free and overlap-free. Hard validity assertions stop
the run; no rollback path exists.

Current limitations include:

- only single-boundary disk topology;
- dynamic legal-region and analytic-center computation remains expensive;
- `q -> 1` still produces poor numerical conditioning;
- mean SD is not uniformly better than mature methods or v3.0 on every mesh;
- tail distortion is not explicitly optimized;
- the boundary basis is more expressive than v3.0 but still does not reproduce
  unrestricted SLIM-like boundaries in general.
