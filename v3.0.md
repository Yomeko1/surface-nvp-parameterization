# v3.0 Release Notes

## Scope

v3.0 adds the isolated `research/mesh_pl_nvp` research pipeline for
mesh-aligned piecewise-linear NVP surface parameterization. The existing v2.4
Affine/Spline implementation remains available and unchanged as a baseline.

Generated experiments, plots, checkpoints, caches, and server instructions are
not part of this release. Input meshes under `data/input/` remain versioned;
`data/output/` remains local and Git-ignored.

## Main change

The v2.4 continuous NVP can have a positive continuous Jacobian while its
vertex-sampled, linearly interpolated output still contains flipped or
overlapping triangles. It therefore validates candidate steps and uses
rollback.

The v3.0 research method instead defines every layer directly on the input
triangulation:

1. A proper graph coloring selects mutually non-adjacent active vertices.
2. Each active vertex obtains a convex one-ring legal region `K_i` from signed
   area half-plane constraints.
3. A radial homeomorphism maps `int(K_i)` to `R^2`.
4. A bounded Real-NVP affine coupling acts in the unconstrained latent space.
5. The inverse radial map returns the vertex strictly inside `K_i`.
6. A fixed convex scaffold outer boundary converts positive orientation of all
   extended faces into a global injectivity condition while allowing the
   original boundary to move.

The PL-NVP trainer contains no rollback branch. A non-finite value or violated
hard orientation assertion stops the run instead of restoring an older model
and continuing.

## Included implementation

- Convex one-ring legal-region construction.
- Differentiable log-barrier analytic centers.
- Explicit radial forward and inverse maps between convex polygons and
  unconstrained 2D space.
- Proper-color mesh coupling with explicit reverse execution.
- Same-color batched dynamic-kernel computation.
- Basic and optional static local-geometry conditioners.
- One-ring scaffold construction for a movable source boundary.
- Pure original-face, 3D-area-weighted symmetric Dirichlet training.
- Mesh-adaptive plateau learning-rate controller without rollback.
- Generic OBJ/USD/USDA runner using v2.4 I/O, Tutte initialization, metrics,
  visualization, and summary utilities.
- Unit, stress, pipeline, and topology tests.

## Default research configuration

The defaults in `research/mesh_pl_nvp/default.yaml` are:

- Tutte circle initialization with geometry scaling.
- 4 coupling cycles, hidden dimension 32, `basic` conditioner.
- `max_log_scale = 0.08`, `max_shift_fraction = 0.04`.
- 12 analytic-center Newton iterations.
- 1000 Adam iterations, learning rate `0.003`, gradient clipping `10.0`.
- Adaptive plateau decay to a minimum learning rate of `0.0001`.
- Scaffold enabled with scale `1.1`.
- CPU and `float64` by default.

## Guarantees and limitations

For a valid disk-topology input, a simple fixed scaffold outer boundary, and
successful finite-precision execution, every coupling sublayer preserves
positive orientation of all extended faces; the resulting extended PL disk map
is globally injective. This is a structural guarantee rather than rollback.

Current limitations:

- Only single-boundary disk topology is supported.
- The radial map becomes ill-conditioned as `q` approaches 1.
- Dynamic legal regions and analytic centers dominate runtime.
- Numerical distortion is not yet consistently competitive with mature
  parameterization methods on every mesh.
- A single scaffold ring can produce jagged source boundaries and local
  high-`q` regions.

These limitations motivate the next phase: improve numerical conditioning,
scaffold/boundary quality, efficiency, and model expressiveness without
reintroducing rollback.
