# Output Archive

Results are grouped by the code version that produced them:

- `v1/`: legacy Affine-NVP and Direct UV runs for five meshes.
- `v2.0/`: release placeholder; no formal output artifacts were committed for v2.0.
- `v2.1/`: shared-scale seed-0 comparisons and Affine/Spline seeds 0-4 results.
- `v2.2/`: Affine/Spline fairness ablation (global transform + capacity matching),
  a spline-bins (4/8/16) ablation, and new Jacobian stretch/condition-number
  metrics, seed 0.

Paths embedded in historical logs, summaries, and manifests record the original
execution locations. They are intentionally preserved even when the containing
directory is moved into this versioned archive.
