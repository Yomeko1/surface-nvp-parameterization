# v2.1 Multi-Seed Results

Affine-NVP and Spline-NVP comparisons across seeds 0-4 for Balls, Cow,
David328, Isis, and NefertitiFace.

- `Balls/`, `Cow/`, `David328/`, `Isis/`, `NefertitiFace/`: per-mesh
  `seed_0`..`seed_4` runs, each with `affine/` and `spline/` result sets.
- `statistics.{csv,json}`: aggregate per-method statistics across seeds.
- `paired.{csv,json}`: paired affine-vs-spline comparisons.
- `summary.{csv,json}` / `runs.json` / `manifest.json`: run metadata and results.
