# v3.2 四类误差与合法性审计

更新：2026-09-21。保留 v3.1 训练目标与风险 LR，只记录误差，不以误差改写学习率、
提前停止、选择 checkpoint 或 rollback。正向非法、非有限和 OOM 仍停止。

## 固定尺度

- D3D：原始 3D 顶点轴对齐包围盒对角线。
- LUV0：初始原网格 UV 包围盒对角线，不含 scaffold，全程固定。
- 尺度只用于报告，训练数据和 SD 不额外重缩放。

## 1. 几何往返

每个原始三角形取三个固定内部样本，实际从 3D 点独立求重心坐标、映射 UV、
再通过面定位和独立坐标求解恢复 3D。报告绝对 L2 距离和距离 / D3D。
按原始 3D 面积均分给样本作为统计权重，报告 max、RMS、p99。
保留已知面与 STRtree 定位两种结果、未命中、多候选和换面计数。
阶段终点另测近边样本、单位正方形 float32 查询和导出解码。
导出使用所选 OBJ/USDA 格式；各格式量化不同，必须标明，不能混作同一误差。
这是固定采样估计，不是连续曲面最坏界，也不包含未知光滑曲面的离散化误差。

## 2. 参数化质量

主列与训练一致：原始面 3D 面积加权 regularized SD，单面为
`sum_j(sigma_j^2 + (sigma_j+1e-4)^-2)`。float64 重算。
strict QR SD 使用 `sum_j(sigma_j^2 + sigma_j^-2)`，独立列。
保留单面按面数 p95/p99/max 和旧 float32 统计作历史解释，不混用。
regularized SD 中的 1e-4 是保留的建模项，不是机器精度。

## 3. 网络数值往返

固定参数下 `F_theta^-1(F_theta(U0)) - U0` 的每顶点 L2 距离 / LUV0，
按原始、辅助和全部顶点分组，所有组共用 LUV0，顶点均匀加权。
同时保存绝对距离、max/RMS/p99、旧最大坐标绝对值。
完整组合与当前阶段单独计算分开；失败保存异常，不把有限子集当全体结果。
status=ok 只表示计算有限，不意味着准确；没有 1e-8 验收线。
这个指标衡量全网格状态空间中的浮点逆，不是曲面点到 UV 的几何逆，也不是撤销 Adam。

## 4. 翻转、自交

负面积为翻转，零面积为退化，非有限单列。方向符号采用浮点过滤，不确定时
由输入浮点数的精确有理数回退判定。原网格、扩展网格和导出原网格分开。
自交按无序面对计数，允许拓扑共享的边/点，禁止共享部分之外的重叠。
GEOS 构造仍为浮点数，不能宣称所有极端输入的精确算术证明。
原始旧版 eps=1e-12 指标另存 legacy_num_flipped，不能冒充真实负面积数。

## 记录和保存顺序

每步记录训练数据，每 50 步及阶段末保存原生 UV、权重、Adam、RNG、调度状态。
先保存固定预算最终网格与自包含模型，再审计，不因网络逆失败丢失合法参数化。
所有快照测面积、SD、几何和网络。全局相交/导出在初值、阶段末和存在的 H2
100/200/300 快照测量；其余相交数为 null（未测），而不是 0。
失败/非有限信息不被有限统计隐藏。自定义快照间隔可能不包含全部里程碑。
源码/输入 hash、配置、依赖、设备、种子、真实执行步数和耗时保留。
新增报告目录必须不存在；不覆盖历史记录。训练和审计耗时分开。

## 限制与 OOM

固定简单 scaffold 外边界与所有扩展面正定向给出圆盘 PL 单射的结构条件；
不等于对任意输入、精度和数值状态无条件担保。最终导出另查量化后的合法性。
OOM 首先保存现场并停止，优先等价的分块/有限内存计算。不得自动减少约束、
精度、模型或训练预算。等价重试仍 OOM 则停止汇报。
`.pt` 含 pickle，只加载可信本地/已验证文件。
